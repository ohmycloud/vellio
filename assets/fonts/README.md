# Noto Serif SC

The reader embeds the full Simplified Chinese Regular (400) and SemiBold (600)
TrueType faces. They are registered for this application process only; no font
installation or runtime network access is required.

Source: [Google Fonts Noto Serif SC](https://github.com/google/fonts/tree/main/ofl/notoserifsc),
retrieved 2026-10-05 from the Google Fonts CSS endpoint:
`https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@400;600&display=swap`.
